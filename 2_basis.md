# Лекция 5. Создание консольных программ на C#

## Словарик к лекции

| Термин | Что означает |
|---|---|
| **Консольное приложение** | Программа без графического интерфейса: общение с пользователем через текст — окно с чёрным фоном и белым текстом (или наоборот) |
| **CLI** *(Command Line Interface)* | Интерфейс командной строки: способ управления программой через ввод текстовых команд |
| **Поток ввода/вывода** | Каналы, через которые программа получает данные (stdin — клавиатура) и отдаёт результаты (stdout — экран) |
| **Точка входа** | Метод, с которого начинается выполнение программы — `Main` |
| **Буфер** | Промежуточное хранилище данных при вводе-выводе |
| **Сборка проекта** *(build)* | Превращение исходного кода в готовую к запуску сборку (.exe/.dll) |

## 5.1. Что такое консольное приложение и зачем оно будущему разработчику

> 📖 **Консольное приложение** — программа, взаимодействующая с пользователем исключительно текстом: она печатает сообщения на экран (в окно терминала/консоли) и читает введённые с клавиатуры строки. У неё нет кнопок, окон и графики.

> 💡 **Аналогия:** если программа с графическим интерфейсом — это ресторан с официантами и красивым интерьером, то консольная программа — это окошко выдачи: просто и по делу. Вы говорите — она отвечает.

**Почему обучение начинается с консоли:**

1. **Ничего лишнего** — вы учитесь именно программировать (логика, данные, алгоритмы), а не рисовать интерфейсы.
2. **Все профессионалы используют консоль** — инструменты разработчика (`dotnet`, `git`, серверы) — консольные программы.
3. **Бэкенд начинается с консоли** — веб-сервер ASP.NET Core внутри запускается... как консольное приложение.
4. **Минимум магии** — весь код на экране, ничего не скрыто в визуальном дизайнере.

## 5.2. Создаём первый проект: два способа

### Способ 1. Командная строка (профессиональный)

Откройте терминал (PowerShell, cmd или терминал в VS Code) и выполните:

```bash
dotnet new console -n HelloApp    # создать проект-консоль с именем HelloApp
cd HelloApp                        # перейти в папку проекта
dotnet run                         # скомпилировать и запустить
```

**Разбор команд:**

| Команда | Что делает |
|---|---|
| `dotnet new console -n Имя` | Создаёт шаблон консольного проекта |
| `dotnet run` | Компилирует (при изменениях) и запускает программу |
| `dotnet build` | Только компилирует, не запуская (проверка ошибок) |
| `dotnet publish -c Release` | Создаёт готовую к распространению сборку |

### Способ 2. Visual Studio / VS Code

- **Visual Studio:** File → New → Project → **Console App** → имя проекта → Create.
- **VS Code:** установите расширение **C# Dev Kit**, затем в терминале VS Code — те же команды `dotnet new console`.

### Что лежит в папке проекта

```
HelloApp/
├── HelloApp.csproj     ← «паспорт» проекта: целевая платформа, зависимости
├── Program.cs          ← ВАШ КОД (точка входа)
├── bin/                ← результат компиляции (готовые .dll/.exe)
└── obj/                ← временные файлы компилятора (не трогаем)
```

Содержимое `HelloApp.csproj`:

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>       <!-- Exe = исполняемая консольная программа -->
    <TargetFramework>net8.0</TargetFramework>  <!-- целевая платформа -->
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
</Project>
```

## 5.3. Анатомия первой программы

Откройте `Program.cs`. Вы увидите:

```csharp
// Вариант A — современный (top-level statements, C# 9+):
Console.WriteLine("Hello, World!");
```

```csharp
// Вариант B — классический вид (то же самое, «под капотом» A):
using System;                          // подключение пространств имён

namespace HelloApp                     // пространство имён — «адрес» ваших классов
{
    class Program
    {
        static void Main(string[] args)   // ТОЧКА ВХОДА: отсюда начинается выполнение
        {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

**Разбор каждого элемента:**

| Элемент | Что это |
|---|---|
| `using System;` | Подключение базовой библиотеки (там живёт класс `Console`) |
| `namespace` | Пространство имён — «контейнер» для классов, чтобы имена из разных библиотек не конфликтовали |
| `class Program` | Главный класс программы |
| `static void Main(string[] args)` | Точка входа. `static` — вызывается без создания объекта; `void` — ничего не возвращает; `args` — аргументы командной строки (см. 5.9) |
| `Console.WriteLine(...)` | Команда «напечатать строку на экран и перейти на новую строку» |

> 💬 **Почему современный вариант короче:** компилятор сам генерирует `class Program` и `Main` — достаточно написать тело программы. Дальше в лекциях используем краткий стиль.

## 5.4. Вывод на экран: Console.Write и Console.WriteLine

Класс `Console` — «пульт связи с консолью». Два главных метода вывода:

| Метод | Поведение |
|---|---|
| `Console.WriteLine(x)` | Напечатать `x` и **перейти на новую строку** |
| `Console.Write(x)` | Напечатать `x` и **остаться** на той же строке |

```csharp
Console.WriteLine("Первая строка");
Console.WriteLine("Вторая строка");
Console.Write("Без");
Console.Write("переноса");
Console.WriteLine("!");     // напечатает: Безпереноса!

// Вывод чисел и выражений — автоматически превращаются в текст:
Console.WriteLine(2 + 2);        // 4  — сначала вычисляется, потом печатается
Console.WriteLine("2 + 2");      // 2 + 2  — в кавычках ТЕКСТ, не вычисляется
Console.WriteLine(10 / 3);       // 3   — целочисленное деление (см. лекцию 6)
Console.WriteLine(10 / 3.0);     // 3.3333333333333335 — дробное деление
```

### Форматированный вывод: три способа подставить значение в текст

```csharp
string name = "Анна";
int age = 20;

// Способ 1 — конкатенация (склеивание) знаком +. Работает, но громоздко:
Console.WriteLine("Привет, " + name + "! Тебе " + age + " лет.");

// Способ 2 — ИНТЕРПОЛЯЦИЯ строк (главный способ, $ перед кавычками):
Console.WriteLine($"Привет, {name}! Тебе {age} лет.");

// Внутри { } можно любое выражение:
Console.WriteLine($"Через год будет {age + 1}");

// Способ 3 — составное форматирование (старый стиль, встречается в чужом коде):
Console.WriteLine("Привет, {0}! Тебе {1} лет.", name, age);
```

### Красивый вывод чисел: спецификаторы формата

```csharp
double price = 1234.5678;

Console.WriteLine($"{price:F2}");     // 1234,57 — F2 = дробная часть, 2 знака
Console.WriteLine($"{price:C}");      // 1 234,57 ₽ — валюта по настройкам ОС
Console.WriteLine($"{price:E2}");     // 1,23E+003 — научная запись
Console.WriteLine($"{price:P1}");     // 123 456,8 % — проценты (умножает на 100)
Console.WriteLine($"{255:X}");        // FF — шестнадцатеричное (см. лекцию 3)
Console.WriteLine($"{1234567:N0}");   // 1 234 567 — с разделителями разрядов

// Выравнивание: {значение, ширина} — дополняет пробелами до ширины
Console.WriteLine($"|{name,10}|");    // |      Анна| — вправо
Console.WriteLine($"|{name,-10}|");   // |Анна      | — влево
```

## 5.5. Ввод с клавиатуры: Console.ReadLine

> 📖 **`Console.ReadLine()`** — метод, который **останавливает программу** и ждёт, пока пользователь наберёт текст и нажмёт Enter. Возвращает введённое как **строку (`string`)** — или `null`, если ввод кончился (Ctrl+Z).

**Ключевое правило, на котором спотыкаются все новички:**

> ⚠️ `ReadLine()` **всегда** возвращает строку. Даже если пользователь ввёл «25» — вы получите строку `"25"`, а не число. Складывать строки с числами нельзя! Нужен **преобразование (парсинг)** — см. ниже.

```csharp
Console.Write("Как тебя зовут? ");     // Write, чтобы курсор остался на строке
string name = Console.ReadLine();       // программа ЖДЁТ ввода

Console.Write("Сколько тебе лет? ");
string ageText = Console.ReadLine();    // получили СТРОКУ, например "20"

// Console.WriteLine(ageText + 1);      // ОШИБКА ЛОГИКИ: "201" — склейка строк!
```

## 5.6. Превращаем строку в число: Parse, TryParse, Convert

Три инструмента превращения строки в число — и чёткое понимание, когда какой:

### Способ 1. `int.Parse` — «преврати или урони»

```csharp
string ageText = "20";
int age = int.Parse(ageText);      // строка → число, теперь можно считать:
Console.WriteLine(age + 1);        // 21 ✓

// ОПАСНО: если пользователь ввёл не число — программа УПАДЁТ с исключением:
// int.Parse("привет")  → FormatException, аварийное завершение
```

### Способ 2. `TryParse` — «попробуй и сообщи» (безопасный, РЕКОМЕНДУЕТСЯ)

> 📖 **`TryParse`** — попытка преобразования без исключений: возвращает `true`/`false` (получилось ли), а результат кладёт в переменную через `out`.

```csharp
Console.Write("Введите возраст: ");
string input = Console.ReadLine();

bool success = int.TryParse(input, out int age);
//                                     └── сюда запишется число, ЕСЛИ получится

if (success)
{
    Console.WriteLine($"Через год будет {age + 1}");
}
else
{
    Console.WriteLine($"'{input}' — это не число. Попробуйте ещё раз.");
}
```

> 💬 **Разбор синтаксиса `out`:** слово `out` означает «метод запишет значение в эту переменную». Мы объявляем `int age` прямо в вызове — переменная создаётся там же.

> 💡 **Аналогия:** `Parse` — слепое доверие («прыгай — разберёмся»); `TryParse` — проверка парашюта перед прыжком. В программах, которые читают ввод пользователя, всегда используйте `TryParse`.

### Способ 3. `Convert` — универсальный преобразователь

```csharp
int a    = Convert.ToInt32("25");       // строка → int
double d = Convert.ToDouble("3.14");
bool b   = Convert.ToBoolean("true");

// ВАЖНО: Convert при неверном вводе ТОЖЕ бросает исключение — как Parse.
```

### Шпаргалка: когда что использовать

| Инструмент | Поведение при ошибке | Когда применять |
|---|---|---|
| `int.Parse(s)` | Исключение `FormatException` | Ввод гарантированно корректен (например, прочитали число из файла, который сами записали) |
| `int.TryParse(s, out x)` | Возвращает `false`, без исключений | **Любой ввод пользователя** — выбор по умолчанию |
| `Convert.ToInt32(s)` | Исключение | Легаси-код; удобно преобразовывать другие типы между собой |

### Запрос числа с повтором до успеха — шаблон для запоминания

```csharp
int ReadPositiveInt(string prompt)             // своя функция: спрашивает число,
{                                              // пока пользователь не введёт корректное
    while (true)
    {
        Console.Write(prompt);
        string input = Console.ReadLine();

        if (int.TryParse(input, out int value) && value > 0)
            return value;                      // успех — возвращаем число

        Console.WriteLine("Нужно целое положительное число, попробуйте ещё раз.");
    }
}

int count = ReadPositiveInt("Сколько раз поздороваться? ");
```

> 💡 Обратите внимание: `&&` — «и»: обе части должны быть истинны. Если `TryParse` вернул `false`, вторая проверка даже не выполняется (короткое замыкание) — ошибки не будет.

## 5.8. Управление внешним видом консоли

```csharp
Console.Title = "Моя программа";                  // заголовок окна

Console.ForegroundColor = ConsoleColor.Green;     // цвет текста
Console.WriteLine("Всё хорошо!");                 // зелёное сообщение
Console.ForegroundColor = ConsoleColor.Red;
Console.WriteLine("Ошибка!");                     // красное
Console.ResetColor();                             // вернуть обычный цвет

Console.BackgroundColor = ConsoleColor.DarkBlue;  // цвет фона текста
Console.Write(" Выделение ");
Console.ResetColor();

Console.Clear();                                  // очистить весь экран

Console.SetCursorPosition(10, 5);                 // переместить курсор: x=10, y=5
Console.Write("Текст в заданной позиции");        // основа для «консольной графики»
```

**Классический приём — цветные сообщения об ошибках:**

```csharp
void PrintColor(string text, ConsoleColor color)
{
    Console.ForegroundColor = color;
    Console.WriteLine(text);
    Console.ResetColor();
}

PrintColor("Успешно!", ConsoleColor.Green);
PrintColor("Предупреждение", ConsoleColor.Yellow);
PrintColor("Ошибка!", ConsoleColor.Red);
```

## 5.9. Аргументы командной строки: string[] args

Программе можно передать данные **при запуске** — ещё до того, как она что-то спросит:

```bash
dotnet run -- Анна 25
```

```csharp
// Параметры args — массив строк из командной строки:
// (в top-level стиле args доступен сразу; в классическом — string[] args в Main)

if (args.Length == 0)
{
    Console.WriteLine("Использование: HelloApp <имя> <возраст>");
    return;    // завершаем программу
}

string name = args[0];                       // первый аргумент
Console.WriteLine($"Привет, {name}!");

if (args.Length > 1 && int.TryParse(args[1], out int age))
    Console.WriteLine($"Тебе {age} лет");
```

> 💬 **Где это встречается:** `git commit -m "текст"`, `dotnet new console -n Имя` — всё это аргументы командной строки. Умение их читать делает ваши утилиты профессиональными.

## 5.10. Сквозной пример: интерактивный калькулятор

Соберём всё изученное в одну работающую программу:

```csharp
// ================== КОНСОЛЬНЫЙ КАЛЬКУЛЯТОР ==================

Console.Title = "Калькулятор v1.0";
Console.WriteLine("=== Калькулятор ===");
Console.WriteLine("Введите два числа и операцию (+, -, *, /)");
Console.WriteLine("Для выхода введите 'q' вместо числа.\n");

while (true)    // главный цикл: работаем, пока пользователь не выйдет
{
    // --- ввод первого числа ---
    Console.Write("Первое число (или q): ");
    string input1 = Console.ReadLine();
    if (input1 == "q") break;                          // условие выхода

    if (!double.TryParse(input1, out double a))        // проверка корректности
    {
        PrintError("Это не число. Повторите ввод.");
        continue;                                      // пропустить итерацию
    }

    // --- ввод второго числа ---
    Console.Write("Второе число: ");
    if (!double.TryParse(Console.ReadLine(), out double b))
    {
        PrintError("Это не число. Повторите ввод.");
        continue;
    }

    // --- ввод операции ---
    Console.Write("Операция (+ - * /): ");
    string op = Console.ReadLine();

    // --- вычисление (switch-выражение, C# 8+) ---
    double? result = op switch     // double? = «число ИЛИ null»
    {
        "+" => a + b,
        "-" => a - b,
        "*" => a * b,
        "/" => b != 0 ? a / b : null,     // делить на ноль нельзя!
        _   => null                        // _ = всё остальное (неизвестная операция)
    };

    if (result is null)
    {
        PrintError(b == 0 && op == "/"
            ? "Деление на ноль невозможно!"
            : "Неизвестная операция.");
    }
    else
    {
        Console.ForegroundColor = ConsoleColor.Green;
        Console.WriteLine($"Результат: {a} {op} {b} = {result:F3}\n");
        Console.ResetColor();
    }
}

Console.WriteLine("Спасибо за использование! Нажмите любую клавишу...");
Console.ReadKey(true);

// --- вспомогательная функция (локальная) ---
void PrintError(string message)
{
    Console.ForegroundColor = ConsoleColor.Red;
    Console.WriteLine("⚠ " + message + "\n");
    Console.ResetColor();
}
```

> 💬 **Что здесь нового и почему работает:**
> - `while (true) ... break` — бесконечный цикл с выходом по команде: типовой каркас диалоговых программ;
> - `continue` — «прервать текущий круг цикла и начать заново»;
> - `double?` — «нулевые» значения: `null` означает «результата нет» (не число, а отсутствие);
> - `switch`-выражение — компактный выбор по значению `op`;
> - локальная функция `PrintError` объявлена внизу, но доступна во всей программе.

## 5.11. Запуск и отладка в Visual Studio

| Действие | Горячая клавиша | Что происходит |
|---|---|---|
| Запуск без отладки | `Ctrl+F5` | Программа выполняется, окно остаётся открытым после завершения |
| Запуск с отладкой | `F5` | Выполняется под управлением отладчика |
| Точка останова | `F9` (на строке) | Программа **остановится** на этой строке — можно изучить значения переменных |
| Шаг с обходом | `F10` | Выполнить строку, не заходя внутрь методов |
| Шаг с заходом | `F11` | Выполнить строку, заходя внутрь вызванных методов |
| Смотреть значение | Навести курсор на переменную | Всплывающая подсказка со значением; окно **Watch** — для контроля |

> 💡 **Главный навык новичка — отладчик, а не угадывание.** Не понимаете, почему программа работает не так? Поставьте точку останова, запустите F5 и смотрите, какие значения реально лежат в переменных. Это быстрее любых размышлений.

## 5.12. Публикация программы: делимся с другими

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

| Флаг | Значение |
|---|---|
| `-c Release` | Оптимизированная сборка (быстрее Debug) |
| `-r win-x64` | Целевая платформа (win-x64, linux-x64, osx-arm64...) |
| `--self-contained true` | Включить рантайм внутрь — работает на машине без установленного .NET (файл больше) |
| `--self-contained false` | Рантайм должен быть установлен (файл маленький) |
| `-p:PublishSingleFile=true` | Всё в один .exe |

## 5.13. Выводы

1. Консольная программа создаётся за минуту: `dotnet new console` + `dotnet run`.
2. Ввод — **только строки** (`Console.ReadLine`), числа получаем через `TryParse` — это защищает от падений.
3. `WriteLine` + интерполяция `$"{...}"` — стандарт вывода; форматы `F2`, `C`, `X` делают вывод красивым.
4. Каркас диалоговой программы: `while (true)` + условие выхода + проверка ввода + понятные сообщения об ошибках.
5. Отладчик (F5, F9, F10) — основной инструмент поиска ошибок.
6. `dotnet publish` превращает проект в распространяемую программу.

## 6.1. Переменные: ячейки для данных

> 📖 **Переменная** — именованная область памяти с указанным типом. Синтаксис объявления: `Тип имя = значение;`

> 💡 **Аналогия:** переменная — **почтовый ящик с табличкой**. Тип — размер ящика (в него «большое» не влезет), имя — надпись на табличке, значение — содержимое. Содержимое можно менять, но только на подходящее по размеру (типу).

```csharp
int age = 20;                 // объявили и сразу инициализировали
double price;                 // можно объявить без значения — но ИСПОЛЬЗОВАТЬ
price = 99.90;                // нельзя, пока не присвоим!

age = 21;                     // меняем значение (тип тот же)

const double TaxRate = 0.20;  // КОНСТАНТА: менять нельзя, компилятор проследит
// TaxRate = 0.25;            // ОШИБКА КОМПИЛЯЦИИ

var count = 10;               // var: компилятор САМ выводит тип по правой части.
var name = "Анна";            // count — это int, name — это string.
                              // var — не «переменная без типа»! Тип всё равно строгий.

// Правила имён: camelCase для переменных (userName),
// PascalCase для классов и методов (GetUserName),
// имя должно объяснять СМЫСЛ: customerCount лучше, чем x2.
```

**Область видимости — где переменная живёт:**

```csharp
{
    int local = 5;        // переменная существует только ВНУТРИ этих фигурных скобок
    Console.WriteLine(local);   // ✓ здесь доступна
}
// Console.WriteLine(local);    // ✗ ОШИБКА: local здесь уже не существует
```

> 💬 **Правило:** переменная живёт от строки объявления до закрывающей скобки блока, где объявлена. Ошибка «the name does not exist» почти всегда значит «вы вышли за границы области видимости» или «объявили не там».

## 6.2. Типы данных: фундамент

### 6.2.1. Обзор базовых типов

| Категория | Типы | Пример литерала |
|---|---|---|
| Целые числа | `int`, `long`, `short`, `byte` | `42`, `1_000_000` |
| Дробные | `double`, `float`, `decimal` | `3.14`, `0.5m` |
| Логический | `bool` | `true`, `false` |
| Символ | `char` | `'A'` (одинарные кавычки!) |
| Текст | `string` | `"Привет"` (двойные кавычки) |
| «Пустое» значение | `null` | только для ссылочных типов |

### 6.2.2. Выбор типа на практике

```csharp
int visitors = 1250;               // счётчики, количества, ID → int
long population = 8_100_000_000L;  // большие числа → long (L — суффикс)
double temperature = 36.6;         // физика, координаты, средние → double
decimal account = 1500.50m;        // ДЕНЬГИ → decimal (m — суффикс)
bool isVip = true;                 // да/нет → bool
char grade = 'A';                  // ОДИН символ → char
string fullName = "Иванов Анна";   // текст → string
```

> ⚠️ **Три частые ошибки с типами:**
> 1. Деньги в `double` → копейки теряются (см. лекцию 3). Только `decimal`!
> 2. `'A'` и `"A"` — разные вещи: `char` и `string`. Одинарные/двойные кавычки — не взаимозаменяемы.
> 3. `10 / 3` = **3**, а не 3,33: если оба операнда целые, деление целочисленное (дробная часть отбрасывается).

### 6.2.3. Преобразования типов

**Неявное** (безопасное, без потерь — «маленькое» в «большое»):

```csharp
int i = 100;
long big = i;        // int → long: помещается всегда, компилятор разрешает
double d = i;        // int → double: тоже безопасно
```

**Явное** (возможна потеря — требуется ручное указание):

```csharp
double pi = 3.99;
int cut = (int)pi;           // ЯВНОЕ: дробная часть ОТБРОШЕНА (не округлена!)
Console.WriteLine(cut);      // 3  — не 4!

// Для округления есть математика:
Console.WriteLine((int)Math.Round(pi));   // 4 — математическое округление
Console.WriteLine(Math.Ceiling(pi));      // 4 — вверх
Console.WriteLine(Math.Floor(pi));        // 3 — вниз
Console.WriteLine(Math.Truncate(pi));     // 3 — просто отбросить дробную часть
```

**Строка ↔ число** — уже знакомо по лекции 5: `int.TryParse`, `int.Parse`, `ToString()`.

```csharp
int n = 42;
string text = n.ToString();          // "42" — число в строку (всегда безопасно)
```

## 6.3. Операторы: действия над данными

### 6.3.1. Арифметические

| Оператор | Смысл | Пример | Результат |
|---|---|---|---|
| `+` `-` `*` | обычные | `7 * 3` | `21` |
| `/` | деление | `7 / 2` | **`3`** (целочисленное!) |
| `/` | деление | `7 / 2.0` | `3.5` (есть double — деление дробное) |
| `%` | **остаток от деления** | `7 % 2` | `1` |
| `++` | +1 | `i++` | |
| `--` | −1 | `i--` | |

> 💬 **Остаток `%` — недооценённый герой.** Классические применения:
> ```csharp
> Console.WriteLine(17 % 2);   // 1 → число нечётное (0 было бы чётным)
> Console.WriteLine(100 % 7);  // 2 → сколько останется, разложив по 7
> Console.WriteLine(125 % 10); // 5 → последняя цифра числа
> Console.WriteLine(minute % 60); // минуты в пределах часа (цикличность)
> ```

**Тонкость `++` — до или после:**

```csharp
int i = 5;
Console.WriteLine(i++);   // 5  — СНАЧАЛА использовать, потом увеличить
Console.WriteLine(i);     // 6

int j = 5;
Console.WriteLine(++j);   // 6  — СНАЧАЛА увеличить, потом использовать
```

> 💡 Совет: на старте пишите `i++` отдельной строкой — не смешивайте с выводом, меньше путаницы.

### 6.3.2. Сравнения — результат всегда `bool`

```csharp
int a = 5, b = 7;
Console.WriteLine(a == b);   // False — равенство (ДВА знака =!)
Console.WriteLine(a != b);   // True  — не равно
Console.WriteLine(a <  b);   // True
Console.WriteLine(a >= b);   // False
```

> ⚠️ **Ошибка №1 всех новичков:** `=` — присваивание, `==` — сравнение. `if (x = 5)` не скомпилируется для чисел (хорошо!), но с `bool` пройдёт — будьте внимательны.

### 6.3.3. Логические операторы

| Оператор | Название | Истинно, когда |
|---|---|---|
| `&&` | И (AND) | **оба** условия истинны |
| `\|\|` | ИЛИ (OR) | **хотя бы одно** истинно |
| `!` | НЕ (NOT) | инвертирует: `!true` → `false` |

```csharp
int age = 25;
bool hasTicket = true;

Console.WriteLine(age >= 18 && hasTicket);   // True — и возраст, и билет
Console.WriteLine(age < 18 || hasTicket);    // True — достаточно одного
Console.WriteLine(!hasTicket);               // False — «нет билета»

// КОРОТКОЕ ЗАМЫКАНИЕ: если первый операнд && ложен, второй НЕ вычисляется:
string s = null;
// if (s.Length > 0 && s != null)  — ПЛОХО: упадёт на s.Length при null
if (s != null && s.Length > 0)    // ХОРОШО: при null вторая часть не выполнится
    Console.WriteLine(s);
```

### 6.3.4. Приоритет операторов (кратко)

Как в математике: `*` `/` `%` выше, чем `+` `-`; сравнения выше, чем `&&`; `&&` выше, чем `||`. Скобки — всегда можно и нужно:

```csharp
Console.WriteLine(2 + 3 * 4);        // 14 — сначала умножение
Console.WriteLine((2 + 3) * 4);      // 20 — скобки меняют порядок
Console.WriteLine(age >= 18 && (hasTicket || isGuest));
```

> 💡 **Правило стиля:** если сомневаетесь в приоритете — ставьте скобки. Читаемость важнее краткости.

## 6.4. Условия: программа принимает решения

### 6.4.1. if / else if / else

```csharp
Console.Write("Введите температуру: ");
double t = double.Parse(Console.ReadLine());

if (t <= 0)
{
    Console.WriteLine("Лёд");
}
else if (t < 100)
{
    Console.WriteLine("Вода");
}
else
{
    Console.WriteLine("Пар");
}
```

**Правила конструкции:**
- проверка идёт **сверху вниз**; выполняется **первая** подошедшая ветка, остальные пропускаются;
- `else` — необязательная «лови всё остальное»;
- фигурные скобки `{}` можно опустить для одной команды, но **новичкам рекомендуем всегда писать** — меньше ошибок.

### 6.4.2. Вложенные условия и логика вместо вложенности

```csharp
// ВЛОЖЕННОСТЬ — работает, но читается тяжело:
if (age >= 18)
{
    if (hasPassport)
    {
        Console.WriteLine("Вход разрешён");
    }
}

// ТО ЖЕ САМОЕ через && — компактнее и яснее:
if (age >= 18 && hasPassport)
    Console.WriteLine("Вход разрешён");
```

### 6.4.3. Тернарный оператор: if в одну строку

```csharp
// условие ? значение_если_да : значение_если_нет
int a = 10, b = 20;
int max = a > b ? a : b;                       // 20

Console.WriteLine($"Статус: {(age >= 18 ? "взрослый" : "ребёнок")}");
```

> 💬 Используйте для **простого выбора значения**. Вложенные тернарники (`a ? b ? c : d : e`) — путь к нечитаемому коду.

### 6.4.4. switch: выбор одного из вариантов

Когда одна переменная сравнивается с набором значений — `switch` нагляднее цепочки `else if`:

```csharp
Console.Write("Введите оценку (2-5): ");
int mark = int.Parse(Console.ReadLine());

switch (mark)
{
    case 5:
        Console.WriteLine("Отлично!");
        break;                    // break ОБЯЗАТЕЛЕН — конец ветки
    case 4:
        Console.WriteLine("Хорошо");
        break;
    case 3:
        Console.WriteLine("Удовлетворительно");
        break;
    case 2:
        Console.WriteLine("Неудовлетворительно");
        break;
    default:                      // «всё остальное»
        Console.WriteLine("Нет такой оценки");
        break;
}
```

**Несколько значений в одной ветке и switch-выражение (современный стиль):**

```csharp
// Классический: несколько case подряд:
string dayType;
switch (dayNumber)
{
    case 1: case 2: case 3: case 4: case 5:
        dayType = "Будний день"; break;
    case 6: case 7:
        dayType = "Выходной"; break;
    default:
        dayType = "Нет такого дня"; break;
}

// Современный switch-ВЫРАЖЕНИЕ (C# 8+): присваивает результат:
string dayType2 = dayNumber switch
{
    >= 1 and <= 5 => "Будний день",     // паттерны с диапазоном!
    6 or 7        => "Выходной",
    _             => "Нет такого дня"   // _ = всё остальное
};
```

> 💡 **Что выбрать:** проверяете диапазоны и сложные условия → `if/else`; выбираете по конкретным значениям одной переменной → `switch`.

## 6.5. Циклы: повторяем действия

Зачем: компьютер силён именно в повторении. Напечатать 1000 строк, обработать массив, ждать ввода — всё это циклы.

### 6.5.1. for — когда известно ЧИСЛО повторений

```csharp
//         ┌─── старт          ┌─── условие продолжения   ┌─── шаг
for (int i = 1;        i <= 5;                        i++)
{
    Console.WriteLine($"Итерация №{i}");
}
// Вывод: Итерация №1 ... Итерация №5

// Перебор с шагом 2:
for (int i = 0; i <= 10; i += 2)
    Console.Write($"{i} ");        // 0 2 4 6 8 10

// Обратный отсчёт:
for (int i = 10; i >= 1; i--)
    Console.Write($"{i} ");        // 10 9 8 ... 1

// Таблица умножения — ВЛОЖЕННЫЕ циклы:
for (int row = 1; row <= 9; row++)
{
    for (int col = 1; col <= 9; col++)
        Console.Write($"{row * col,4}");   // выравнивание ширины 4
    Console.WriteLine();                   // перевод строки после ряда
}
```

**Разбор анатомии for:**

```
for (инициализация; условие; шаг)
{
    тело;
}
```

Порядок работы: ① инициализация (один раз) → ② проверка условия → ③ тело → ④ шаг → ② проверка → ③ тело... пока условие не станет ложным.

### 6.5.2. while — когда повторяем ПОКА условие истинно

```csharp
int sum = 0;
int number = 1;

while (sum <= 100)              // «пока сумма не перевалит за 100»
{
    sum += number;              // += это sum = sum + number
    number++;
}
Console.WriteLine($"Достаточно сложить числа от 1 до {number - 1}");  // 14
```

⚠️ **Бесконечный цикл** — классическая ошибка: забыли изменить переменную условия.

```csharp
// int i = 0;
// while (i < 10)
//     Console.WriteLine(i);   // i никогда не растёт → цикл ВЕЧНЫЙ (Ctrl+C!)
```

### 6.5.3. do-while — выполнит тело ХОТЯ БЫ РАЗ

```csharp
string password;

do
{
    Console.Write("Введите пароль: ");
    password = Console.ReadLine();
} while (password != "qwerty");     // проверка ПОСЛЕ тела → тело точно исполнится 1 раз

Console.WriteLine("Доступ разрешён!");
```

> 💡 **Как выбрать цикл:**
> | Ситуация | Цикл |
> |---|---|
> | Знаю, сколько раз повторить | `for` |
> | Повторять, пока условие верно; может не выполниться ни разу | `while` |
> | Сначала спросить, потом проверять (меню, пароль) | `do-while` |
> | Перебрать элементы коллекции | `foreach` (чуть ниже) |

### 6.5.4. break и continue — управление циклом

```csharp
// break — немедленно ВЫЙТИ из цикла:
for (int i = 1; i <= 100; i++)
{
    if (i * i > 500)
    {
        Console.WriteLine($"Первый квадрат больше 500: {i}²={i * i}");
        break;                       // дальше проверять бессмысленно
    }
}

// continue — ПРОПУСТИТЬ остаток итерации, перейти к следующей:
for (int i = 1; i <= 10; i++)
{
    if (i % 2 != 0)
        continue;                    // нечётные пропускаем
    Console.Write($"{i} ");          // 2 4 6 8 10
}
```

### 6.5.5. foreach — элегантный перебор коллекций

```csharp
string[] fruits = { "яблоко", "банан", "вишня" };

foreach (string fruit in fruits)     // «для каждого элемента...»
{
    Console.WriteLine(fruit);        // индексы не нужны — просто элементы!
}
```

> ⚠️ В `foreach` нельзя изменять коллекцию (добавлять/удалять элементы) — только читать.

## 6.6. Массивы: много значений под одним именем

> 📖 **Массив** — фиксированный набор элементов **одного типа**, хранящихся в памяти подряд, с доступом по **индексу**.

> ⚠️ **Железное правило: индексация начинается с 0.** Первый элемент — `[0]`, последний — `[длина − 1]`. Обращение за границы → исключение `IndexOutOfRangeException`.

```csharp
// ── Создание ────────────────────────────────────────
int[] scores = new int[5];              // массив из 5 нулей (значения по умолчанию)
int[] primes = { 2, 3, 5, 7, 11 };      // сразу с значениями — размер вычислится
string[] names = new string[3];         // массив из 3 null'ов

// ── Доступ по индексу ───────────────────────────────
Console.WriteLine(primes[0]);           // 2  — ПЕРВЫЙ элемент
Console.WriteLine(primes[4]);           // 11 — ПОСЛЕДНИЙ (5 − 1)
Console.WriteLine(primes.Length);       // 5  — длина (без скобок!)

primes[2] = 99;                         // запись: заменяем 5 на 99
// Console.WriteLine(primes[5]);        // ✗ ПАДЕНИЕ: индексов 0..4, пять — вне границ

// ── Перебор ─────────────────────────────────────────
for (int i = 0; i < primes.Length; i++)      // классика: нужен индекс
    Console.Write($"{primes[i]} ");

foreach (int p in primes)                    // лаконично: нужен только элемент
    Console.Write($"{p} ");

// ── Полезные операции ───────────────────────────────
int[] data = { 8, 3, 15, 6, 1 };

int sum = 0;
foreach (int x in data) sum += x;
Console.WriteLine(sum);                      // 33

Console.WriteLine(data.Max());               // 15 — максимум (System.Linq)
Console.WriteLine(data.Min());               // 1
Console.WriteLine(data.Average());           // 6,6
Array.Sort(data);                            // сортировка на месте: 1 3 6 8 15
Array.Reverse(data);                         // разворот
```

**Классический алгоритм — поиск максимума вручную** (важно понимать механику, не только `Max()`):

```csharp
int[] numbers = { 8, 3, 15, 6, 1 };
```

## 6.7. Методы: разбиваем программу на части

> 📖 **Метод** — именованный блок кода, который можно вызывать многократно. Синтаксис: `ВозвращаемыйТип Имя(параметры) { тело }`

> 💡 **Зачем:** метод — это **глагол с именем**. Вместо того чтобы каждый раз писать «возьми список, пройди по нему, сравни с текущим максимумом...», вы пишете `FindMax(numbers)` — код читается как предложение.

### 6.7.1. Первые методы

```csharp
// void = метод НИЧЕГО не возвращает, просто выполняет действия

{
    Console.WriteLine("====================");
}

void GreetUser(string name)            // параметр — «входные данные» метода
{
    Console.WriteLine($"Привет, {name}!");
}

// Методы с ВЕРНУТЫМ значением:
int Square(int x)
{
    return x * x;                      // return = «вернуть результат и выйти»
}

double GetAverage(int a, int b)
{
    return (a + b) / 2.0;              // 2.0 — чтобы деление было дробным!
}

// ── Вызовы ──
PrintLine();                           // скобки ОБЯЗАТЕЛЬНЫ даже без параметров
```

## 6.10. Исключения: программа не падает, а обрабатывает ошибки

> 📖 **Исключение (exception)** — объект, сигнализирующий об ошибке времени выполнения. Возникнув, оно «всплывает» вверх по коду; если его никто не перехватил — программа аварийно завершается. Перехват — конструкцией `try/catch`.

```csharp
Console.Write("Введите число: ");
string input = Console.ReadLine();

try
{
    int n = int.Parse(input);            // здесь МОЖЕТ возникнуть FormatException
    Console.WriteLine($"100 / n = {100 / n}");   // здесь МОЖЕТ возникнуть DivideByZeroException
}
catch (FormatException)                  // перехватываем КОНКРЕТНЫЙ тип
{
    Console.WriteLine($"'{input}' — не целое число.");
}
catch (DivideByZeroException)
{
    Console.WriteLine("На ноль делить нельзя!");
}
catch (Exception ex)                     // ЛОВУШКА ВСЕГО — всегда последняя!
{
    Console.WriteLine($"Неожиданная ошибка: {ex.Message}");
}
finally
{
    Console.WriteLine("Блок finally: выполняется ВСЕГДА — с ошибкой или без.");
}
```

**Разбор конструкции:**

| Блок | Назначение |
|---|---|
| `try { }` | «Подозрительный» код, который может упасть |
| `catch (Тип) { }` | План действий при конкретной ошибке. Блоков может быть несколько — выбирается первый подходящий по типу |
| `catch (Exception ex)` | Универсальный перехват; `ex.Message` — текст ошибки, `ex.StackTrace` — где произошла. Ставить **только последним** |
| `finally { }` | Выполняется **в любом случае** (была ошибка или нет) — для освобождения ресурсов (закрыть файл, соединение) |

**Порядок catch важен:** от частных типов к общему `Exception`, иначе общий блок «съест» всё раньше частных.

**Взаимосвязь TryParse и try/catch:** для **ожидаемых** пользовательских ошибок — `TryParse` (быстро, без «исключений как потока управления»); `try/catch` — для неожиданных ситуаций (файл недоступен, сеть отвалилась).

## 6.11. Мини-проект: «Менеджер задач» (консольный)

Финальный пример, связывающий **все** темы лекции. Изучите его построчно — здесь каждый элемент из разделов 6.1–6.10:

```csharp
// ================== КОНСОЛЬНЫЙ МЕНЕДЖЕР ЗАДАЧ ==================
// Демонстрирует: списки, циклы, условия, методы, switch, TryParse, строки

List<(string Title, bool Done)> tasks = new();   // список кортежей: текст + статус

while (true)                                     // главный цикл программы
{
    ShowMenu();
    string choice = Console.ReadLine();

    switch (choice)
    {
        case "1": AddTask(); break;
        case "2": ShowTasks(); break;
        case "3": CompleteTask(); break;
        case "4": RemoveTask(); break;
        case "0":
            Console.WriteLine("До встречи!");
            return;                              // выход из программы
        default:
            Print("Нет такой команды.", ConsoleColor.Red);
            break;
    }
    Console.WriteLine();
}

// ────────── методы ──────────

void ShowMenu()
{
    Print("══ МЕНЮ ЗАДАЧ ══", ConsoleColor.Cyan);
    Console.WriteLine("1 — добавить задачу");
    Console.WriteLine("2 — показать все");
    Console.WriteLine("3 — отметить выполненной");
    Console.WriteLine("4 — удалить");
    Console.WriteLine("0 — выход");
    Console.Write("Ваш выбор: ");
}

void AddTask()
{
    Console.Write("Текст задачи: ");
    string title = Console.ReadLine()?.Trim();    // ?. — вызвать Trim, если не null

    if (string.IsNullOrWhiteSpace(title))
    {
        Print("Пустая задача — не добавляю.", ConsoleColor.Yellow);
        return;
    }
    tasks.Add((title, Done: false));
    Print("Задача добавлена!", ConsoleColor.Green);
}

void ShowTasks()
{
    if (tasks.Count == 0)
    {
        Print("Список пуст.", ConsoleColor.Yellow);
        return;
    }

    for (int i = 0; i < tasks.Count; i++)
    {
        var (title, done) = tasks[i];                       // распаковка кортежа
        string icon  = done ? "☑" : "☐";
        var   color  = done ? ConsoleColor.DarkGray : ConsoleColor.White;

        Console.ForegroundColor = color;
        Console.WriteLine($"{i + 1,2}. {icon} {title}");    // выравнивание номера
        Console.ResetColor();
    }
}

void CompleteTask()
{
    if (!TryReadTaskNumber("Номер выполненной задачи: ", out int index)) return;

    tasks[index] = (tasks[index].Title, Done: true);
    Print("Готово! ✅", ConsoleColor.Green);
}

void RemoveTask()
{
    if (!TryReadTaskNumber("Номер удаляемой задачи: ", out int index)) return;

    tasks.RemoveAt(index);
    Print("Задача удалена.", ConsoleColor.Green);
}

// Общий помощник: безопасно спрашивает номер задачи (от 1 до Count)
// и переводит его в индекс (от 0 до Count-1)
bool TryReadTaskNumber(string prompt, out int index)
{
    index = -1;
    if (tasks.Count == 0)
    {
        Print("Список пуст.", ConsoleColor.Yellow);
        return false;
    }

    Console.Write(prompt);
    if (!int.TryParse(Console.ReadLine(), out int n) ||
        n < 1 || n > tasks.Count)
    {
        Print($"Нужно число от 1 до {tasks.Count}.", ConsoleColor.Red);
        return false;
    }
    index = n - 1;                       // человек считает с 1, массив — с 0!
    return true;
}

void Print(string text, ConsoleColor color)
{
    Console.ForegroundColor = color;
    Console.WriteLine(text);
    Console.ResetColor();
}
```

> 💬 **Что здесь продемонстрировано:**
> - `while (true)` + `switch` — каркас меню-программы (лекция 5 + 6.4.4);
> - `List<(string, bool)>` с кортежами — простая структура данных без создания класса;
> - `TryReadTaskNumber` — **общий** помощник вместо дублирования проверки в двух методах (принцип DRY — Don't Repeat Yourself);
> - везде `TryParse` и проверки границ — программа **не падает** ни при каком вводе;
> - локальные методы — логика разбита по смыслу, главный цикл читается как оглавление.

## 6.12. Выводы

1. **Переменные** строго типизированы; имя должно объяснять смысл; `const` — для неизменных значений.
2. **Типы:** `int` — целые, `double` — дробные расчёты, `decimal` — деньги, `bool` — логика, `string` — текст. Помните: `10/3 = 3`; `'A'` ≠ `"A"`; `=` ≠ `==`.
3. **Условия:** `if/else` — диапазоны и логика; `switch` — выбор по значениям; тернарник — выбор значения в одну строку.
4. **Циклы:** `for` — известно число повторов, `while` — «пока условие», `do-while` — «хотя бы раз», `foreach` — перебор коллекций. `break` — выйти, `continue` — пропустить итерацию.
5. **Массивы** — фиксированный размер, индексация с 0, длина `.Length`; **List&lt;T&gt;** — растёт динамически, длина `.Count`.
6. **Методы** — основа читаемого кода: одна задача — один метод; `TryParse`-стиль (`bool` + `out`) — образец безопасного API.
7. **Строки неизменяемы** — методы возвращают новые строки; присваивайте результат обратно.
8. **Исключения:** `try/catch/finally`; для ожидаемого пользовательского ввода — `TryParse`, а не исключения.
