# 📖 Справочник терминов курса «Введение»

> **Как пользоваться справочником:**
> - Термины разделены на два блока: **латиница (A–Z)** и **кириллица (А–Я)** — ищите в том разделе, как привыкли произносить.
> - Колонка **Л** показывает, в какой лекции термин вводится: **Л1** — история C#, **Л2** — платформа .NET, **Л3** — данные и системы счисления, **Л4** — ООП.
> - Стрелка **→** означает «см. также».
> - Если ищете русский термин, а его нет — проверьте латинский блок (например, «сборка мусора» → **GC**).

## 🚀 Экспресс-минимум: 20 понятий, без которых никуда

Если запомнить только это — уже можно разговаривать на языке профессии:

1. **C#** — язык; **.NET** — платформа, на которой он работает
2. **Компилятор** — переводит ваш код в код, понятный компьютеру
3. **Бит** — 0 или 1; **байт** — 8 бит
4. **Машинный код** — инструкции, которые процессор понимает напрямую
5. **IL-код** — промежуточный язык, в который компилируется C#
6. **JIT** — перевод IL в машинный код во время работы программы
7. **CLR** — среда исполнения .NET
8. **GC (сборщик мусора)** — автоматически освобождает память
9. **Класс** — чертёж; **объект** — конкретный экземпляр по чертежу
10. **Поле / свойство / метод** — данные / контролируемый доступ / поведение
11. **Конструктор** — код, выполняющийся при создании объекта
12. **Инкапсуляция** — прятать внутренности, давать доступ по правилам
13. **Абстракция** — показывать «что», скрывать «как»
14. **Наследование** — «собака является животным»
15. **Полиморфизм** — один вызов, разное поведение
16. **Интерфейс** — контракт «что умеем» без деталей
17. **Кроссплатформенность** — работает на Windows, Linux, macOS
18. **LTS / STS** — долгая (3 года) / короткая (18 мес.) поддержка версии
19. **ASP.NET Core** — веб-фреймворк .NET
20. **decimal** — единственный правильный тип для денег

# ⚖️ Раздел «Не путать!»

Пары, которые чаще всего смешивают новички:

| ❓ Вопрос | Ответ |
|---|---|
| **C# vs .NET** | C# — **язык** (правила записи кода); .NET — **платформа** (среда исполнения + библиотеки). На .NET работают также F# и VB.NET |
| **.NET Framework vs .NET 5+** | Framework — старая Windows-only платформа (заморожена на 4.8); .NET 5+ — современная кроссплатформенная. Новые проекты — только .NET 5+ |
| **.NET Standard vs .NET Core** | Standard — **спецификация** (документ-договор о наборе API), Core — **платформа** (реализация). Стандарт не исполняет код! |
| **JIT vs AOT** | JIT — перевод IL в машинный код **во время работы** (по методам, с кэшем); AOT — перевод **всего кода заранее**. JIT: гибкость; AOT: мгновенный старт |
| **Компиляция vs интерпретация** | Компиляция — перевод кода заранее; интерпретация — построчное исполнение по ходу |
| **Бит vs байт** | Бит — 0/1; байт — **8 бит** (256 значений, 0–255) |
| **Двоичная vs шестнадцатеричная** | Обе — лишь **записи** одного и того же числа. Hex — компактная «стенография» двоичной: 1 hex-цифра = 4 бита |
| **float/double vs decimal** | float/double — **двоичные** дроби (IEEE 754), приближённые; decimal — **десятичный**, точный. Деньги — только decimal |
| **Перегрузка vs переопределение** | Перегрузка (overload) — несколько методов **одного класса** с одним именем и разными параметрами; переопределение (override) — наследник **заменяет** метод родителя |
| **virtual vs abstract** | virtual — метод **имеет реализацию**, наследник *может* переопределить; abstract — метод **пуст**, наследник *обязан* реализовать. Абстрактный класс нельзя инстанцировать |
| **Абстрактный класс vs интерфейс** | Абстрактный класс — общий код + состояние, один родитель; интерфейс — чистый контракт, реализовать можно много |
| **Поле vs свойство** | Поле — просто переменная (сырые данные); свойство — методы доступа get/set с возможностью проверок. Наружу выставляют свойства |
| **Наследование vs композиция** | «Является» (is-a) → наследование; «имеет» (has-a) → композиция. `Dog : Animal` ✓; `Car : Engine` ✗ |
| **Класс vs объект** | Класс — чертёж (один); объект — экземпляр по чертежу (много, каждый независим) |
| **STS vs LTS** | STS — 18 месяцев поддержки (нечётные версии); LTS — 3 года (чётные). Для продакшена — LTS |
