# Основы C#: создание консольных программ

---

## Урок 1. Создание и запуск консольной программы

### Шаг 1. Открываем терминал

Windows: нажмите `Win + R`, введите `cmd`, нажмите Enter.

### Шаг 2. Создаём проект — одна команда

```bash
dotnet new console -o MyApp
```

Эта команда создаст папку `MyApp` с готовой программой внутри.

### Шаг 3. Заходим в папку

```bash
cd MyApp
```

### Шаг 4. Запускаем

```bash
dotnet run
```

В терминале появится:

```
Hello, World!
```

**Всё. Программа работает.** Дальше мы меняем код в файле `Program.cs` (откройте его в любом редакторе — Блокнот, VS Code), сохраняем и снова пишем `dotnet run`.

## Урок 2. Точка входа — метод Main

### Где начинается программа

Программа **всегда начинается с метода `Main`**. Это как входная дверь: компилятор ищет `Main` и выполняет код внутри его фигурных скобок `{ }` сверху вниз.

```csharp
using System;

namespace MyApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Программа запустилась!");
            Console.WriteLine("Эти две строки напечатал Main");
        }
    }
}
```

### Что означает каждая строка

| Строка | Простыми словами |
|---|---|
| `using System;` | Служебная строка. Даёт доступ к `Console`. **Просто оставляйте как есть.** |
| `namespace MyApp` | Имя вашего проекта. **Не трогаем.** |
| `class Program` | Класс — «контейнер», в котором лежит весь код. **Не трогаем.** |
| `static void Main(string[] args)` | Точка входа. **Отсюда программа стартует.** |
| `string[] args` | Аргументы запуска. **Пока не нужны, не трогаем.** |
| `Console.WriteLine(...)` | Команда «напечатать строку на экран». |

### Главное правило

Весь ваш код пишите **внутрь фигурных скобок Main**:

```csharp
static void Main(string[] args)
{
    // ВЕСЬ ваш код — здесь
}
```

## Урок 3. Класс с полями и методами

### Два понятия — и всё

- **Поле** — это данные (что объект *имеет*).
- **Метод** — это действие (что объект *умеет делать*).

Пример: у собаки есть имя и возраст (поля), и она умеет лаять (метод).

### Пишем класс

Класс — это шаблон. Сначала описываем шаблон, потом создаём по нему объекты.

```csharp
class Dog
{
    // ПОЛЯ — данные собаки
    public string Name;
    public int Age;

    // МЕТОД — действие собаки
    public void Bark()
    {
        Console.WriteLine("Гав! Меня зовут " + Name);
    }
}
```

### Создаём объект и используем его

Внутри `Main`:

```csharp
static void Main(string[] args)
{
    Dog dog = new Dog();   // 1. Создали собаку по шаблону
    dog.Name = "Шарик";    // 2. Записали в поле Name значение
    dog.Age = 3;           // 3. Записали в поле Age значение

    dog.Bark();            // 4. Вызвали метод — собака залаяла
}
```

Вывод:

```
Гав! Меня зовут Шарик
```

### Правило точки

Через **точку** мы обращаемся к содержимому объекта:

```csharp
dog.Name = "Шарик";   // записать в поле
dog.Bark();           // вызвать метод
```

### Полная программа целиком (можно копировать и запускать)

```csharp
using System;

namespace MyApp
{
    class Dog
    {
        public string Name;
        public int Age;

        public void Bark()
        {
            Console.WriteLine("Гав! Меня зовут " + Name);
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Dog dog = new Dog();
            dog.Name = "Шарик";
            dog.Age = 3;

            dog.Bark();
        }
    }
}
```

Обратите внимание: класс `Dog` написан **рядом** с классом `Program`, а не внутри него.

## Урок 4. Взаимодействие полей и методов

Методы внутри класса могут **читать** поля и **изменять** поля. В этом и есть вся суть.

### 1. Метод читает поля

```csharp
public void PrintInfo()
{
    Console.WriteLine("Имя: " + Name + ", возраст: " + Age);
}
```

Метод просто берёт значения полей и печатает их.

### 2. Метод изменяет поле

```csharp
public void Birthday()
{
    Age = Age + 1;
    Console.WriteLine(Name + " подрос! Теперь ему " + Age);
}
```

Вызвали метод — поле `Age` увеличилось на единицу.

### 3. Метод считает, используя поле, и возвращает результат

```csharp
public int GetAgeInDogYears()
{
    return Age * 7;
}
```

Метод берёт поле `Age`, умножает на 7 и отдаёт результат через `return`.

### Проверяем всё вместе

```csharp
using System;

namespace MyApp
{
    class Dog
    {
        public string Name;
        public int Age;

        public void PrintInfo()
        {
            Console.WriteLine("Имя: " + Name + ", возраст: " + Age);
        }

        public void Birthday()
        {
            Age = Age + 1;
            Console.WriteLine(Name + " подрос! Теперь ему " + Age);
        }

        public int GetAgeInDogYears()
        {
            return Age * 7;
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Dog dog = new Dog();
            dog.Name = "Шарик";
            dog.Age = 3;

            dog.PrintInfo();     // Имя: Шарик, возраст: 3

            dog.Birthday();      // Шарик подрос! Теперь ему 4

            int dogYears = dog.GetAgeInDogYears();
            Console.WriteLine("По-собачьи это " + dogYears);   // 28

            dog.PrintInfo();     // Имя: Шарик, возраст: 4  ← поле изменилось!
        }
    }
}
```

Обратите внимание на последнюю строку: после `Birthday()` метод `PrintInfo()` печатает **уже новый возраст**. Это и есть взаимодействие: поле изменилось — все методы теперь видят новое значение.

---

## Шпаргалка: запомнить пять вещей

1. **Создать проект:** `dotnet new console -o MyApp`, зайти `cd MyApp`, запустить `dotnet run`.
2. **Программа начинается с `Main`** — весь код пишем в его скобках.
3. **Поле** = данные, **метод** = действие.
4. **Создание объекта:** `Dog dog = new Dog();`, доступ через точку: `dog.Name`, `dog.Bark()`.
5. **Методы работают с полями:** читают (`Name`), изменяют (`Age = Age + 1`), возвращают (`return Age * 7`).

# Справочник терминов

*Все термины из уроков — простыми словами. Если забыл, что значит слово — ищи здесь.*

---

## Терминал и проект

| Термин | Что это простыми словами |
|---|---|
| **Терминал** | Окно, где можно вводить текстовые команды компьютеру вместо мышки. Открывается: `Win + R` → набрать `cmd` → Enter |
| **Команда** | Текстовая инструкция для терминала. Например, `dotnet run` — команда «запусти программу» |
| **dotnet** | Программа-помощник, которая умеет создавать и запускать проекты на C#. Все команды начинаются с её имени: `dotnet ...` |
| **Проект** | Папка с файлами вашей программы. Создаётся командой `dotnet new console -o Имя --use-program-main` |
| **Program.cs** | Главный файл проекта. Именно в нём мы пишем код. `.cs` — расширение файлов с кодом C# (си-шарп) |
| **dotnet run** | Команда: собрать программу и сразу запустить |
| **dotnet build** | Команда: только собрать программу (проверить, что нет ошибок), не запуская |
| **Сборка / компиляция** | Превращение вашего текстового кода в программу, которую умеет выполнять компьютер |
| **Ошибка компиляции** | Сообщение, что в коде опечатка или нарушение правил. Программа не запустится, пока не исправите |

---

## Слова внутри кода

| Термин | Что это простыми словами |
|---|---|
| **using System;** | Служебная строка вверху файла. Даёт доступ к командам вроде `Console.WriteLine`. Просто оставляйте как есть |
| **namespace** (пространство имён) | Имя-ярлык для группы классов. Совпадает с именем проекта. Не трогаем |
| **class** (класс) | Шаблон/чертёж. Описывает, какие данные (поля) и действия (методы) будут у объектов |
| **Main** (точка входа) | Метод, с которого программа **начинает работу**. Компьютер ищет `Main` и выполняет код в его скобках `{ }` |
| **static** | Служебное слово. Пока просто пишем его перед `Main` и методами, вызываемыми из `Main`, не задумываясь |
| **void** | Означает «метод ничего не возвращает» — просто делает действие и всё |
| **string[] args** | Аргументы командной строки. Пока не нужны — просто часть записи `Main`, не трогаем |
| **public** | Означает «открыто». Поле или метод видны снаружи класса. Пока ставим `public` везде |
| **new** | Команда «создать объект по шаблону». Например: `Dog dog = new Dog();` |

---

## Строки кода

| Термин | Что это простыми словами |
|---|---|
| **Console** | Класс для работы с окном консоли: печатать и читать текст |
| **Console.WriteLine("...")** | Напечатать текст и **перейти на новую строку** |
| **Console.Write("...")** | Напечатать текст **без перехода** на новую строку |
| **Console.ReadLine()** | Подождать, пока пользователь что-то напечатает и нажмёт Enter. Вернёт введённый текст |
| **Точка с запятой `;`** | Знак конца команды. Каждая команда в коде заканчивается им. Забыли — будет ошибка |
| **Фигурные скобки `{ }`** | Контейнеры для кода. В `{ }` метода лежит его код. Открывающая `{` и закрывающая `}` всегда парные |
| **Круглые скобки `( )`** | Используются у методов: `Main( )`, `Bark( )`. Внутри — параметры |
| **Комментарий** | Текст после `//`, который игнорируется программой. Пишут пояснения для людей: `// здесь считаем сумму` |
| **+ (в тексте)** | Склеивание строк: `"Меня зовут " + Name` превратится в `Меня зовут Шарик` |

## Данные

| Термин | Что это простыми словами |
|---|---|
| **Переменная** | Именованная коробочка для хранения значения: `int age = 3;` |
| **Тип данных** | Какое содержимое можно положить в переменную: целое число, дробное, текст и т.д. |
| **int** | Целые числа: `3`, `100`, `-50` |
| **double** | Дробные числа: `1.5`, `3.14` |
| **string** | Текст в двойных кавычках: `"Шарик"` |
| **char** | Один символ в одинарных кавычках: `'A'` |
| **bool** | Только два значения: `true` (да) или `false` (нет) |
| **Значение** | То, что лежит в переменной. У `age = 3` значение — число 3 |

## Логика (условия и циклы)

| Термин | Что это простыми словами |
|---|---|
| **if** | «Если». Делает код в скобках, только когда условие верно |
| **else** | «Иначе». Делает код, когда условие if не сработало |
| **Условие** | Проверка, которая даёт `true` или `false`. Например: `age >= 18` |
| **switch** | Выбор из нескольких готовых вариантов (как меню) |
| **case** | Один вариант в switch: «если день равен 1 — сделать это» |
| **break** | Стоп. В switch — выйти после варианта. В цикле — прервать цикл совсем |
| **continue** | Пропустить текущий повтор цикла и перейти к следующему |
| **for** | Цикл-счётчик: повторить код известно сколько раз. `for (int i = 1; i <= 5; i++)` — пять повторов |
| **while** | Цикл «пока»: повторять, пока условие верно. Число повторов заранее неизвестно |
| **do-while** | Цикл, который делает тело **минимум один раз**, потом проверяет условие. Подходит для меню |
| **i++** | Увеличить на 1. То же самое, что `i = i + 1` |
| **== ** | Сравнение «равно ли». Не путать с одним `=` (записать значение)! |
| **%** | Остаток от деления. `10 % 3` = 1 (делим 10 на 3, остаётся 1). Так проверяют чётность: `x % 2 == 0` |

## Массивы

| Термин | Что это простыми словами |
|---|---|
| **Массив** | Коробка с пронумерованными ячейками для нескольких значений одного типа |
| **Элемент** | Одно значение внутри массива |
| **Индекс** | Номер ячейки. **Нумерация с нуля!** Первый элемент — `arr[0]`, второй — `arr[1]` |
| **Length** | Свойство «сколько всего ячеек». `numbers.Length` — длина массива |
| **new int[5]** | Создать массив на 5 ячеек (все пустые, нули) |
| **{ 10, 20, 30 }** | Создать массив и сразу заполнить значениями |

## Методы, поля, объекты

| Термин | Что это простыми словами |
|---|---|
| **Метод** | Действие, которое умеет делать объект. Пишется как блок кода с именем: `Bark()`, `PrintInfo()` |
| **Поле** | Данные, которые объект имеет: `Name`, `Age` |
| **Объект** | Реальная «вещь», созданная по шаблону-классу. Из одного класса `Dog` можно сделать много собак |
| **Параметр** | Данные, которые метод принимает внутрь: в `PrintSum(int a, int b)` параметры — `a` и `b` |
| **return** | «Верни ответ». Метод отдаёт результат наружу: `return Age * 7;` |
| **int (перед методом)** | Тип результата, который метод возвращает. `public int GetAge()` вернёт целое число. `void` — ничего не вернёт |
| **Вызов метода** | Запуск действия: пишем имя объекта, точку, имя метода и скобки: `dog.Bark();` |
| **Точка `.`** | Знак доступа к содержимому объекта: `dog.Name` — поле, `dog.Bark()` — метод |
| **Конструктор** | Специальный метод, который срабатывает при создании объекта и сразу заполняет поля: `new Student("Иван", 19)` |
| **Свойство** | То, что можно прочитать у объекта, но это не поле-коробочка, а вычисляемое значение (как `Length` у массива) |

---

## Мини-словарь «не путай»

| Путают | Разница |
|---|---|
| `=` и `==` | `=` — записать значение (`x = 5`). `==` — сравнить (`if (x == 5)`) |
| `Write` и `WriteLine` | `WriteLine` после текста переходит на новую строку, `Write` — нет |
| `int.Parse` и `Console.ReadLine` | `ReadLine` всегда даёт **текст**. `int.Parse` превращает текст в число |
| Класс и объект | Класс — чертёж, объект — реальная вещь по чертежу |
| Поле и метод | Поле — то, что объект **имеет**. Метод — то, что он **делает** |
| `break` и `continue` | `break` — выйти из цикла совсем. `continue` — пропустить один повтор |
